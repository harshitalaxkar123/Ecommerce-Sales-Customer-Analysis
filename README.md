# E-commerce Sales & Customer Analysis

## Project Overview
An end-to-end data analytics project using Python, SQL, MySQL, Pandas and Matplotlib to analyze online retail transactions, sales performance and customer purchasing behaviour.

## Technologies Used
- Python
- MySQL
- SQL
- Pandas & NumPy
- Matplotlib & Seaborn
- SQLAlchemy
- Excel

## Project Workflow
1. Data collection using the UCI Online Retail II dataset.
2. Data cleaning and preprocessing using Python.
3. Exploratory Data Analysis (EDA).
4. Customer segmentation using RFM analysis.
5. Loading sales transactions into MySQL.
6. SQL-based business analysis and views.
7. Python-MySQL integration.
8. Business visualization and reporting.

## Key Analysis
- Monthly revenue and order trends
- Top-performing countries
- Best-selling products
- Customer spending behaviour
- Repeat vs one-time customers
- RFM-based customer segmentation
